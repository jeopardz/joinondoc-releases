JoinOnDoc ใช้ข้อมูลอะไรบ้าง

สิทธิ์ที่ขอใช้ทำอะไร
อีเมลของบัญชี Googleระบุตัวผู้ใช้และตรวจว่าเป็นผู้ที่ได้รับอนุญาต
Google Sheetsอ่านและเขียนชีทแคมเปญ และแท็บของระบบในชีทสรุป
Google Driveคัดลอกชีทแคมเปญจาก Template และเก็บไฟล์ PDF ของเอกสาร
Gmailค้นเมล PO ที่เกี่ยวกับแคมเปญ สร้างร่างเมลถึงลูกค้า และส่งเมลแจ้งผู้ตรวจภายในองค์กร
การเชื่อมต่อบริการภายนอกส่งข้อมูลเอกสารไปยังระบบบัญชี PEAK และใช้ AI อ่านไฟล์ PO เมื่อผู้ใช้สั่ง

ข้อมูลไปที่ไหน

  • งานทั้งหมดทำผ่าน Google Apps Script ภายใต้สิทธิ์ของผู้ใช้เอง ข้อมูลอยู่ในบัญชี Google ของผู้ใช้และขององค์กร ไม่มีเซิร์ฟเวอร์อื่นเก็บข้อมูลไว้
  • ข้อมูลเอกสาร (รายการ ยอดเงิน ข้อมูลลูกค้า) ถูกส่งไป PEAK เพื่อออกเอกสารในบัญชีของบริษัท
  • เมื่อผู้ใช้สั่งให้ AI อ่าน PO ระบบจะส่งข้อความหรือไฟล์ PO นั้นไปประมวลผลที่ OpenAI
  • โทเคนการล็อกอินเก็บบนเครื่องของผู้ใช้ เข้ารหัสด้วย Windows (DPAPI)
  • ไม่ขายข้อมูล ไม่ใช้ข้อมูลเพื่อโฆษณา และไม่แบ่งปันให้บุคคลอื่นนอกจากที่ระบุไว้ข้างต้น

การใช้ข้อมูลจาก Google API

การใช้และการส่งต่อข้อมูลที่ได้จาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

JoinOnDoc Privacy Policy (English)

Effective 25 November 2026.

Data accessed: your Google account email (to identify you and check you are authorized); Google Sheets (read/write campaign sheets and the system tab of the summary sheet); Google Drive (copy campaign sheets from a template and store document PDFs); Gmail (search campaign-related purchase-order emails, create draft emails to customers, and send internal review notifications); external requests (send document data to the PEAK accounting system and, when you ask, send a purchase-order text or file to OpenAI for reading).

Where data goes: all processing runs through Google Apps Script under your own authorization; data stays in your and your organization's Google accounts — there is no other server storing it. Document data is sent to PEAK to create the company's documents; purchase-order content is sent to OpenAI only when you use the AI reading feature. Sign-in tokens are stored on your computer encrypted with Windows DPAPI. We do not sell data, use it for advertising, or share it with anyone other than as described above.

Google API data: JoinOnDoc's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: at any time via myaccount.google.com/permissions, or sign out in the app to delete its token on that computer.
