# JoinOnDoc — ช่องทางปล่อยรุ่น

repo นี้เก็บเฉพาะไฟล์โปรแกรม `JoinOnDoc.exe` ของแต่ละรุ่น (ในหน้า Releases) เพื่อให้ JoinOnDoc Launcher ตรวจและอัปเดตรุ่นใหม่ให้อัตโนมัติ

- ไม่มีซอร์สโค้ด ไม่มีค่าตั้งค่า และไม่มีกุญแจใดๆ
- การติดตั้งเครื่องใหม่ใช้ชุดติดตั้งที่ได้รับจากผู้ดูแลระบบ ไม่ใช่ไฟล์ในหน้านี้
- ทุกรุ่นระบุ `SHA256 (JoinOnDoc.exe): …` ไว้ในบันทึกรุ่น Launcher จะตรวจค่านี้ก่อนติดตั้ง
